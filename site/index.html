Roll back before anyone notices.

  • Promote any preview to production

Server rendering and functions, no config.

Next.js apps run as real servers: SSR, streaming, route handlers and server actions work as written. Put a file in /api and it's an endpoint. Warm instances answer fast, and responses with s-maxage are cached at the edge.

  • Streaming React Server Components
  • Node and Web-standard function handlers
  • Static assets served straight from the edge
app/page.js
// Rendered on every request
export const dynamic = "force-dynamic";

export default async function Page() {
  const orders = await getOrders();
  return (
    <Suspense fallback={<Skeleton />}>
      <Dashboard orders={orders} />
    </Suspense>
  );
}

Built in

Everything a deploy needs. Nothing to bolt on.

Live build logs

Watch every step stream in as it runs, and come back to them any time.

Build cache

Dependencies are reused when your lockfile hasn't changed, so repeat builds skip the install.

Isolated builds

Each build runs in its own throwaway container with CPU and memory limits.

Sandboxed runtime

Every project's code runs as its own user, walled off from other projects and the private network.

Environment variables

Separate values for production and previews, available at build time and at runtime.

Monorepos

Deploy any folder of a workspace. Dependencies install from the root, and Turborepo builds run in order.

Redirects, rewrites, headers

Routing rules are checked at build time and applied at the edge.

API and tokens

Everything in the dashboard is an API call. Create tokens for CI and scripts.

Switching is easy

Coming from Vercel? Bring your config.

Orbit reads vercel.json as written: build settings, redirects, rewrites, headers, and per-function memory, duration and included files. Import the repo, update your DNS, and you're done.

  • Node (req, res) and Web Request → Response handlers
  • __dirname and includeFiles for functions that read data
  • Cache-Control: s-maxage honored at the edge
vercel.json
{
  "outputDirectory": "dist",
  "cleanUrls": true,
  "functions": {
    "api/*.js": {
      "includeFiles": "dist/data/**",
      "memory": 1024
    }
  },
  "rewrites": [
    { "source": "/blog/:slug", "destination": "/api/post" }
  ]
}
