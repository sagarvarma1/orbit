# Security policy

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/sagarvarma1/orbit/security/advisories/new)
rather than in a public issue. Include steps to reproduce and the version or commit you tested.

You'll get a reply within a few days. Fixes are released as soon as possible, with credit if you'd like it.

Orbit runs untrusted build code by design. Reports about escaping the Docker build sandbox, the function
sandbox, authentication, or one deployment affecting another are especially welcome.
